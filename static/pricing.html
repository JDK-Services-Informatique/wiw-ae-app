Questions fréquentes

Les réponses pour adopter la version 100% HTML/CSS/JS.

Comment déployer ces pages ?

Il suffit d'héberger le dossier static/ sur un CDN, GitHub Pages ou tout serveur de fichiers.

Y a-t-il des dépendances ?

Aucune. Tout est écrit en HTML5, CSS et JavaScript vanilla pour rester autonome.

Puis-je personnaliser le style ?

Oui, modifiez styles.css et réutilisez les classes utilitaires (cards, steps, plans).
